Why this page exists

CrowdVolt's login sits behind Cloudflare Turnstile, which the Xvfb Chrome on this box never clears — that's a browser-fingerprint problem, not the IP. api.crowdvolt.com itself is not IP-gated, so the fix is to mint the session in a desktop browser where Turnstile passes and carry it here. That's all this page does.
